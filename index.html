設定

Face ID

尚未設定。啟用後可直接用 Face ID 解鎖，PIN 仍保留作為備援。

使用 Safari / PWA 的 Passkey + WebAuthn PRF，把解鎖金鑰綁定到裝置驗證；App 不會取得你的臉部資料。

自動鎖定

App 離開背景超過 30 秒會鎖定；也可設定操作閒置時間。

iCloud 加密備份

按「立即備份」後，App 產生一個已加密檔案。iPhone 會跳出分享選單，請選「儲存到檔案」→ iCloud Drive。

上次產生備份 尚未備份

備份檔本身已加密，還原時需要該份資料的 App PIN。Face ID 設定不會寫進備份檔。

🧯 舊版資料救援

若這個環境仍偵測得到 V1 舊資料，可用舊 PIN 合併回目前密碼本；不會刪除目前資料。

PIN 與安全

資料使用隨機主金鑰 + AES-GCM 加密。PIN 只用來解開主金鑰，不直接保存。

加入 iPhone 主畫面

Safari 開啟網站 → 分享 →「加入主畫面」→ 開啟「作為網頁 App」。
